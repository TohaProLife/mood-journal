# Отчет по статическому анализу безопасности

## Инструменты

- **Semgrep** — SAST-анализатор, ищет уязвимости по паттернам (SQL-инъекции, XSS и тд)
- **Bandit** — анализатор безопасности для Python (проверяет использование опасных функций, хардкод паролей и тд)

### Что проверялось

Bandit проверил все Python-файлы в backend/:
- database.py — подключение к БД
- main.py — точка входа FastAPI
- models.py — модели SQLAlchemy
- schemas.py — Pydantic-схемы
- routers/entries.py — API-эндпоинты

### Почему проблем не найдено

1. **Нет SQL-инъекций** — используется ORM (SQLAlchemy), а не сырые SQL-запросы
2. **Нет хардкод-паролей** — приложение не использует авторизацию
3. **Нет eval/exec** — не используются опасные функции выполнения кода
4. **Валидация входных данных** — Pydantic проверяет все данные на входе (mood 1-5, note до 1000 символов)

### Что можно улучить в будущем

- Добавить CORS-настройки (сейчас FastAPI принимает запросы откуда угодно)
- Вынести строку подключения к БД в переменные окружения вместо хардкода в коде
- Добавить rate limiting на API чтобы защититься от спама

## Интеграция в CI

Оба инструмента добавлены в GitHub Actions pipeline:
- Semgrep запускается через Docker-образ `semgrep/semgrep`
- Bandit ставится через pip и генерирует JSON-отчет
- Отчет Bandit сохраняется как artifact в GitHub Actions
