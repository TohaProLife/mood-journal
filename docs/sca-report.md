# Отчет по анализу зависимостей (SCA)

## Инструменты

- **pip-audit** — проверяет Python-зависимости на известные уязвимости (CVE) через базу PyPI Advisory
- **Trivy** — сканер контейнеров, проверяет все пакеты в Docker-образе (не только Python)

## Результаты

pip-audit проверил все прямые и транзитивные зависимости по базе уязвимостей PyPI. Уязвимостей не найдено — все пакеты свежих версий.

## Почему это важно

Даже если свой код безопасен, уязвимости могут быть в библиотеках которые ты используешь. Например:
- В старых версиях starlette были XSS-уязвимости
- В старых версиях certifi были проблемы с сертификатами
- SQLAlchemy раньше имел проблемы с SQL-инъекциями в определенных сценариях

Регулярная проверка зависимостей помогает найти и обновить уязвимые библиотеки до того как их начнут эксплуатировать.

## Рекомендации

1. Зафиксировать версии зависимостей (pip freeze > requirements.lock)
2. Регулярно обновлять зависимости
3. Настроить Dependabot в GitHub для автоматических PR при обнаружении CVE

## Интеграция в CI

- **pip-audit** — запускается в job `SCA - Dependency Audit`, генерирует JSON-отчет как artifact
- **Trivy** — сканирует Docker-образ в job `Trivy Container Scan`, выводит таблицу с CRITICAL и HIGH уязвимостями
